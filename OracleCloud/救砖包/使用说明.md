### 一、写盘
1. DD
   ```
   sudo dd if=debian.raw of=/dev/sdb bs=16M conv=fsync status=progress
   sync
   ```
3. 将 GPT 移至盘尾
   ```
   apt install -y gdisk
   sgdisk -e /dev/sdb
   ```
4. 让内核重读分区表
   ```
   partprobe /dev/sdb || true
   udevadm settle
   ```
5. 检查是否有错误
   ```
   fdisk -l /dev/sdb | head -n 30
   ```
6. 快速验证
   ```
   mount /dev/sdb1 /mnt
   df -h /mnt
   umount /mnt
   ```

### 二、扩容根分区
1. 使用 growpart
   ```
   apt install -y cloud-guest-utils
   growpart /dev/sdb 1
   ```
2. 然后扩容 ext4 文件系统
   ```
   e2fsck -f /dev/sdb1
   resize2fs /dev/sdb1
   ```
3. 检查结果
   ```
   lsblk /dev/sdb
   ```
